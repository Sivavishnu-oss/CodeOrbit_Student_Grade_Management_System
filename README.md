# Student Grade Manager

A console-based Java application for managing student marks and generating performance statistics. It supports adding student records, viewing them in a formatted table, searching, deleting records, and generating a summary report with averages, highest/lowest scores, pass rate, and grade distribution.

## Technologies Used

- Java (JDK 17 or higher — uses switch expressions)
- `java.util.Scanner` for console input
- `java.util.ArrayList` / `java.util.List` for data storage

## Features

- Add new student records with input validation
- Load sample demo data
- Display all students in a formatted table
- Generate a summary report (average, highest/lowest marks, pass rate, grade distribution)
- Search students by name
- Delete student records

## Setup Instructions

### Prerequisites
- Java Development Kit (JDK) 17 or higher installed
- Verify installation:
  ```bash
  java -version
  javac -version
  ```

### Steps

1. Clone the repository:
   ```bash
   git clone <YOUR_GITHUB_REPO_URL>
   cd StudentGradeManager
   ```

2. Compile the source code:
   ```bash
   javac StudentGradeManager.java
   ```

3. Run the application:
   ```bash
   java StudentGradeManager
   ```

4. Follow the on-screen menu to add, view, search, or delete student records.
